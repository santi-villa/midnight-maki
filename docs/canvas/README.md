# Kit para el canvas de Midnight Maki

| Carpeta | Contenido |
|---|---|
| `01-menu/` | Pantalla de título (vertical y horizontal), creador de personaje, menú del juego (+ `menu.md`) |
| `02-historia/` | Las 7 imágenes de la animación inicial y `historia.md` con el resumen, los textos de cada escena, la carta y los capítulos |
| `03-personajes/` | Retrato y cuerpo entero de cada personaje, ilustrados de los mapaches, clientes y `personajes.md` con las descripciones |
| `04-zonas/` | Cada zona completa, `fachadas/` con los edificios ampliados y `zonas.md` |
| `05-extras/` | Pedidos, mapa, diario, recetario y minijuego de cocina |

Todas las imágenes de personajes y fachadas son pixel art ampliado con píxeles nítidos. Las capturas de menú son de celular (390×844, doble densidad) salvo las horizontales.
